# Roadmap

## Phase 0 — Foundation

- Define service boundaries, provider-neutral product catalogue and target audiences.
- Validate Infomaniak and Proton partner/reseller conditions.
- Decide code license before shipping a reusable implementation.
- Define pricing inputs and support scope without publishing unverified prices.

## Phase 1 — Operational pilot

- Build a reproducible dedicated Nextcloud test deployment.
- Test backups, restores, monitoring, upgrades and offboarding.
- Document manual customer onboarding and contractual prerequisites.
- Offer assisted assessment and implementation services only where commercially authorized.

## Phase 2 — First customer offering

- Launch a simple bilingual (Norwegian/English-ready) landing page.
- Create a minimal internal register of customers and subscribed services.
- Offer documented support and service descriptions.
- Validate costs and margins using real pilot measurements.

## Phase 3 — Automation

- Integrate Ploos Deploy where mature enough for production.
- Add Ploos Domains DNS automation where documented and supported.
- Implement approved partner integrations where APIs and agreements permit.
- Add customer self-service, billing integration and Forenio onboarding only when operationally justified.

## Explicit non-goals at the outset

Building a new identity platform, payment processor, DNS service, deployment engine, or general-purpose public-cloud infrastructure.
